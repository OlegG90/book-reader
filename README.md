# Book Reader

A compact e-book reader for Windows (Android planned) with a local library and, later, access to a
Calibre-Web-Automated / Calibre library. Started as a fork of [Simple Reader](https://github.com/OlegG90/simple-reader).

- Formats: EPUB, FB2 (`.fb2`, `.fb2.zip`)
- Paginated or scrolled reading, table of contents, footnote pop-ups
- A library folder with covers, search and filters; books from elsewhere can be copied or moved in
  under one naming pattern ("Author/Series NN - Title")
- Remembers your place in every book; local bookmarks
- A single portable `breader.exe` — no installer

See [docs/spec.md](docs/spec.md) for the specification and [docs/roadmap.md](docs/roadmap.md) for the stages.

## Usage

```
breader book.epub            # open a book (each file gets its own window)
breader                      # the library (first run: choose its folder)
breader --no-save book.fb2   # just take a look: don't remember the position
breader --register           # offer Book Reader for .epub, .fb2 and .fbz (current user)
breader --help
```

Settings and reading positions are stored in `breader.json` next to the exe
(or in `%APPDATA%ook-reader` if that folder is read-only).

## Development

Requires Node.js, Rust (MSVC toolchain), Visual Studio Build Tools with the C++ workload and, on
Windows on ARM64, LLVM (`winget install LLVM.LLVM`): the TLS library compiles C with clang there
(`src-tauri/.cargo/config.toml` points at it).

```
npm install
npx tauri dev -- -- samples/alice-in-wonderland.epub  # dev mode with a sample book
npm test                 # frontend (vitest) and backend unit tests
npm run build:win        # portable x64 exe: src-tauri/target/x86_64-pc-windows-msvc/release/breader.exe
npm run build            # this machine's architecture: src-tauri/target/release/breader.exe
npm run clean            # remove build outputs (dist, src-tauri/target)
```

### Android

The Android SDK and NDK have no Windows-on-ARM64 builds, so the APK is built in GitHub Actions
([android.yml](.github/workflows/android.yml)) on every push that touches the app: download the
`book-reader-apk` artifact and install it with `adb install` (`adb` is in Google's platform-tools; a debug
APK from another run needs `adb uninstall com.olegg90.bookreader` first). The TLS library needs the NDK's clang to build for Android, so Android compile errors show up in CI. The Gradle project in `src-tauri/gen/android` is kept in the repo.
On the phone the library is `Documents/Books`, reached with the *All files access* permission.

Sample books are in [samples/](samples/): public-domain EPUBs from Project Gutenberg and FB2 files
(windows-1251 and a UTF-8 `.fb2.zip`) generated by `python scripts/make-fb2-samples.py`.
